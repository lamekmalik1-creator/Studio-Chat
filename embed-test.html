This is a separate diagnostic page. It does not change the normal Studio Chat tabs.

How to test: Wait 10–20 seconds for each panel. If the Perchance tool itself appears and you can use its controls inside the panel, embedding works. If you see a browser error, blank panel, or “refused to connect”, embedding is blocked for that page. The links below open the same tools directly for comparison.
