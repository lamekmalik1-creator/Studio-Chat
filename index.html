Install Studio Chat

Android (Chrome): open this site, tap the browser menu ⋮, then choose Install app or Add to Home screen.

Desktop: use the install icon in the address bar, or the Install app button when it appears.

Studio Chat can cache its own app shell. Perchance tools still require internet access.
