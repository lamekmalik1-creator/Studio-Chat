01 / DESIGN

Character generator

Open directly ↗

Use Perchance's character generator to create a visual character portrait. For a written personality, greeting and backstory, continue in Character Chat.

If the generator does not appear inside the app, use Open character generator in browser.

02 / ROLEPLAY

Character chat

Open directly ↗

Create or select a character, set up their personality and scenario, then chat with them using Perchance's own chat interface.

If chat is blocked in the embedded view, open Perchance Character Chat. Chat history and character data may be stored by Perchance in that browser's own storage.

03 / CREATE

Standalone image generator

Generate images independently of the character chat. Describe the subject, choose a canvas size and send the prompt to Perchance.

This uses Perchance's iframe + postMessage image interface. If it is unavailable, use the standalone Perchance image generator.

Perchance Studio is an independent frontend and is not affiliated with Perchance. AI tools require an internet connection and remain subject to Perchance availability and usage rules.

Install Perchance Studio

Android (Chrome): open this site from its GitHub Pages URL, tap the browser menu ⋮, then choose Install app or Add to Home screen.

Desktop (Chrome/Edge): use the install icon in the address bar, or the Install app button when it appears.

The app shell can open offline after its first visit. Perchance's generators still need internet access.
